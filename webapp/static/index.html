Getting started

Guide

Workspace

Problems select the active decision problem and its available model and parameters. Scenarios let you inspect configured what-if assumptions and associated results where stored. Recent Runs open existing optimization history without contacting the LLM; you can rename or hide runs without deleting their history.

Conversation

Ask questions or request analysis in natural language. Try “Show me the current baseline.”, “Run Bonsai with pallet_cost = 200.”, or “Create a high-demand scenario.” Non-default changes may require approval.

Decision View

The right panel displays structured results, KPIs, assumptions, validation, approvals, capability limitations, errors, and historical runs.

Approvals

Consequential or non-default actions may pause for explicit approval. Approve and Reject act on the already prepared deterministic plan.

Problem switching

Bonsai Packaging and Production Capacity Planning are separate problems. Switching is explicit; requests for another problem can be rejected until you select it.

Developer details

Expand the technical details on an interaction to inspect its plans, tool traces, capability decisions, approval metadata, execution ledger, and provenance. This is optional for normal use.

Connections

Settings → Connections configures your provider, API key, model, and connection profile. Saved API keys remain on the server and are not displayed in the browser.
